# SWYNEX-Data-Preparation
## 📊 Data Preparation & Cleaning Project

This project was completed as part of my **Data Analyst Internship at SWYNEX Technologies**.

The main objective of this task was to prepare and clean a healthcare dataset using **Power Query in Power BI**, making the data suitable for further analysis and visualization.

---

## 🎯 Project Objective

The objective of this project was to:

- Clean and prepare the raw healthcare dataset
- Remove duplicate records
- Handle missing values
- Clean text fields
- Correct data types
- Standardize date and numerical columns
- Prepare the dataset for analysis in Power BI

---

## 🗂️ Dataset

The dataset contains healthcare-related information such as:

- Patient details
- Medical conditions
- Admission Date
- Doctor
- Hospital
- Insurance Provider
- Billing Amount
- Room Number
- Admission Type
- Discharge Date
- Medication
- Test Results
- Department

---

## 🧹 Data Cleaning & Preparation

The following steps were performed using **Power Query Editor**:

1. Imported the healthcare dataset into Power BI.
2. Promoted the correct row as column headers.
3. Changed columns to appropriate data types.
4. Removed duplicate records.
5. Replaced missing Doctor values with **"Unknown"**.
6. Trimmed unnecessary spaces from text values.
7. Cleaned text columns.
8. Converted date columns into proper date format.
9. Converted numerical fields into appropriate numeric data types.
10. Reviewed the cleaned dataset for consistency and accuracy.
